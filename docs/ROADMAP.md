# Roadmap

## Fase 0 — Foundation
- documentación base
- estructura del repositorio
- backlog inicial
- reglas de prompts y ownership

## Fase 1 — Core orchestration
- Telegram bot
- Orchestrator API
- MongoDB + Redis
- PM Agent
- modelo de estados y eventos
- GitHub integration básica

## Fase 2 — Execution agents
- Frontend Agent
- Backend Agent
- DevOps Agent
- asignación por dominio
- reporting consolidado

## Fase 3 — Delivery model
- carpeta `/projects/<name>`
- empaquetado de entregables
- checklist de entrega
- metadata por proyecto

## Fase 4 — Deployment on demand
- extracción a repo dedicado
- GitHub Actions por proyecto
- bootstrap en Linode
- guía de rollback

## Fase 5 — NightCityVerse
- presencia de agentes
- estados visuales
- canales internos
- demo operativa
